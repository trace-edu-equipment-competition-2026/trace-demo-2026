# UI 제작 기준

사용자 제공 이미지가 시각 기준이다. 이 문서는 확정된 레퍼런스와 초기 구현 제안을 구분한다.

## 레퍼런스
- 짙은 녹색 사이드바, 회백색 배경, 흰 패널, 민트 강조.
- TRACE 로고, 현재 수업 선택, 하단 교수자 프로필.
- 메뉴: 수업 대시보드 / 프로젝트 · 과제 생성 / 학생별 평가 지원 / 팀별 모니터링 / 과목 설정.
- 첫 활성 메뉴: 교수자 수업 대시보드.
- 이미지의 예시 정보: 2학년 네트워크 실습 / 한국 폴리텍 / 강병준 교수님.
- 메뉴 항목 수와 최초 제품 범위의 5개 화면은 동일한 개념이 아니다. 현재 프로필 선택으로 교수자·학생 역할을 전환하며 학생은 여섯 메뉴를 사용한다.

## 구현 제안
- 데스크톱 1280–1920px, 태블릿 가로 1024–1366px, 세로 768–1024px에서 확인.
- 넓은 화면에는 고정 사이드바, 좁은 태블릿에는 접을 수 있는 내비게이션을 검토.
- 터치 대상 최소 44px, hover에만 의존하지 않음. 가로 넘침 방지.
- 한국어 줄바꿈과 글자 위계 우선. 의미 없는 카드·그라데이션·장식 애니메이션 남발 금지.
- 모션은 패널/탭/상태 전환에만 목적 있게 적용하고 reduced-motion 존중.
- 과제 생성보드는 과제 설계 → AI 운영 방식 → 학생 화면 미리보기의 세 단계로 구현한다. 각 단계 내 세로 스크롤을 허용한다.

## 확정된 공통 구조

네트워크 실습은 실습 폼이 연결된 장비 콘솔을 사용한다. 융합 팀 프로젝트는 실습 폼 연결 없이 팀이 선택한 도구의 산출물·검증 조건·관찰 결과와 해석을 제출한다. 같은 역할에서는 `WorkspaceSidebar`와 공통 내비게이션과 카드 스타일을 사용한다. 교수자 대시보드·평가 지원·모니터링·과목 설정의 풍부한 기존 구성을 두 시나리오에 함께 적용하며, 과제 생성도 같은 세 단계이다. 학생은 팀 대시보드 / 프로젝트 작업실 / 팀 자료 / 팀 채팅 / 개인 AI 지원 / 나의 학습 기록을 사용한다. 작업실의 기획·기술 선택 / 수행 보드 / 실행 및 검증 탭도 공통이다. 과목 출처를 분류하는 지식 연결 카드는 제거하며, 필요한 개념은 가이던스에서 문제의 맥락에 맞게 설명한다.

공통 화면은 기존 녹색·민트 팔레트를 유지하고 제목·수치·보조 설명의 위계를 강화한다. 평가 기준과 교수자 판단을 과정증거 상세와 나란히 배치하고 가이던스·실제 행동은 같은 상세 영역에서 전환해 검토한다. 교수자에게 개인 대화 원문을 표시하지 않으며 지원 요약·공유 요청·수행 근거만 제공한다. 데이터, AI 응답, 실행 결과와 추정 평가는 시연용임을 명시한다.


## 평가 검토 작업대

학생 정보와 강점·보완점을 확인한 뒤, 왼쪽 평가 요소와 오른쪽 근거를 한 작업대에서 대조한다. 넓은 화면은 `minmax(280px,.78fr) / minmax(0,1.6fr)` 비율과 20px 간격을 사용하며 평가 요소만 상단 20px 위치에 고정된다. 1100px 이하에서는 작업대를 세로로 쌓고 평가 요소를 두 열로, 650px 이하에서는 한 열로 표시한다. 전체 피드백 작성과 저장은 작업대 다음에 둔다.

평가 막대는 가장 큰 배점을 공통 최대 눈금으로 삼는다. 채운 길이는 추정 충족 점수, 옅은 구간과 끝 표시는 배점을 뜻하며, 점수와 배점 숫자를 함께 읽게 한다. 근거가 부족하면 0점 대신 산정 대기로 표시한다. 선택한 평가 요소의 추정 이유를 상세 상단에서 읽고, 증거 목록이나 단계 필터를 바꾸면 보이는 자료에 맞게 선택 맥락도 바뀐다. 증거 선택 목록은 원자료 위의 두 열 그리드에 배치하며, 원자료·학생 설명·AI 해석·교수자 확인의 구분은 유지한다.

가이던스는 선택한 사건의 막힌 지점 → 제공한 도움 → 후속 행동 요약 → 기록된 근거 순서로 먼저 읽는다. 연결된 자료가 계획인지 검증 결과인지 구분하고, 지원 효과는 원자료를 대조해 판단한다. 지원 수준·분포 차트는 아래의 펼치기 영역에 둔다. L1–L4는 지원 수준이며 능력 점수가 아니다.

## 학생 팀 대시보드와 실행 연결

프로젝트 개요 다음에는 지금 이어갈 작업과 최근 실행 결과를 배치한다. 작업과 결과는 `1fr / 1.15fr` 두 열을 사용하고 650px 이하에서 세로로 쌓는다. 이어서 팀원별 현재 수행·최근 공유 기록, 팀 자료의 작성자·버전, 다음 확인 작업, 교수자 지도를 보여준다. 긴 과제 안내와 팀 계획은 펼치기 영역에 둔다.

최근 실행 결과는 고정 예시 카드가 아니라 해당 시나리오의 로컬 모의 실행 상태를 읽는다. 실행 대상·규칙·검증 상태·출력·판단 설명을 보관해 작업실 이동과 새로고침 후에도 이어가며, 아직 실행하지 않았다면 결과가 나타날 위치를 안내한다. 정해진 검증 조건과 판단 설명을 갖추면 팀 자료와 개인 학습 기록으로 공유한다. 실제 장비·코드·API에 연결되었다는 의미는 아니다. 네트워크 실습과 융합 팀 프로젝트 모두 같은 화면 마크업에 각 시나리오 데이터를 넣는다.

## 세부 검토와 시각화

평가 막대와 역량 관찰 막대는 민트·보라·노랑·코랄·차콜의 공통 범주색을 사용한다. 과제 진행 차트의 색은 필터로 과제를 숨겨도 과제별로 유지한다. 색 변화는 막대의 수치 의미를 바꾸지 않으며 평가 막대의 공통 절대 배점 눈금을 유지한다. 좁은 분포 구간에는 긴 글자를 넣지 않고 바깥 범례에 이름과 건수를 표시한다.

평가 요소와 증거 선택은 흰 바탕에 녹색 테두리로 표시한다. 교수자 확인과 전체 피드백 입력은 중립색 바탕을 사용하고 AI 해석의 연보라색 영역과 구분한다. 주요 근거·설명·입력 및 저장 조작은 14px로 읽히게 하며 시간·출처 등 보조 정보만 더 작게 표시한다. 공통 패널 간격은 24px, 900px 이하에서는 22px, 600px 이하에서는 18px 토큰을 따르며 1600px 이상 패널 내부 여백은 기존 28px을 유지한다.

과정증거는 수행 기록·계획·자기 설명으로 구분한다. 수행 단계별 건수에는 수행 기록만 포함하고 계획·자기 설명은 별도 필터에서 확인한다. 평가 상세의 ‘충족 근거와 남은 조건’을 펼치면 연결 자료, 추가로 확인할 조건과 시연용 추정 방식이 드러난다. 학생이 실제로 작성한 요청과 AI가 정리한 요약을 같은 출처처럼 표현하지 않는다.

핵심 역량 관찰 비율은 조회 대상 학생과 선택 과제의 조합 중 관찰 조건에 맞는 기록이 있는 조합의 비율이다. 역량 점수나 능력 순위로 해석하지 않는다. 항목을 선택하고 집계 기준을 펼치면 조건·대상·분자와 분모·누락 건수·학생별 원자료 링크를 확인한다. 기준이 없으면 ‘미집계’로 표시하고, 기록이 없다고 미수행이나 능력 부족으로 단정하지 않는다.
