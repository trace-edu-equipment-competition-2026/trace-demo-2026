# coolicons 출처

사용자가 지정한 Figma 파일에서 use_figma의 SVG_STRING export로 추출.
https://www.figma.com/design/VzzWxzLU6o45nOr9dOiHg9/?node-id=17102-2265

제작: Kryston Schwarze / coolicons. 원본 SVG: `public/icons/`. 통합 심볼: `public/icons.svg`. 색상은 CSS mask를 통해 TRACE 토큰을 사용.
사용 아이콘: Add_Plus, Close_MD, Check, Arrow_Right_MD, Arrow_Left_MD, Chevron_Down, Users_Group, User_Circle, Settings, File_Edit, List_Checklist, More_Grid_Small, Hamburger_MD, Save, Download.
