# 학생 작업실

구현: `StudentWorkspace.tsx`, `WorkspaceSidebar.tsx`, `ProjectSimulation.tsx`, `TeamDocuments.tsx`, `scenarios.ts`.
네트워크·융합 동일 화면 사용. 과목 출처별 지식 연결 카드는 현재 미사용. 필요한 개념은 가이던스에 반영.

## 메뉴

| 경로 | 화면 | 역할 |
| --- | --- | --- |
| `team` | 팀 대시보드 | 현재 작업·최근 실행·팀원·자료·교수자 지도 |
| `studio` | 프로젝트 작업실 | 기획·기술 선택 / 수행 보드 / 실행 및 검증 |
| `documents` | 팀 자료 | 검색·분류·작성·수정·첨부·다운로드 |
| `chat` | 팀 채팅 | 팀 메시지·팀 AI 가이던스·자료 링크 |
| `ai` | 개인 AI 지원 | 개인 예시 대화·판단 공유·교수자 요청 |
| `learning` | 나의 학습 기록 | 수행 증거·교수자 지도·평가 피드백 |

프로필: 강병준 교수자 / 유송민 학생·1팀. 실제 로그인 아님.
수업 전환 시 역할·메뉴·작업실 탭 유지. 새로고침은 기본 교수자·네트워크 화면.
키보드 선택·현재 상태·외부 클릭 닫기·Escape 지원.

## 기획·수행

기획: 이름·대상·문제·최소 범위·언어/명령·도구·처리/연결 방식·협업 도구·선택 이유.
모든 필드 입력 후 저장. 개인 기획 증거 기록.
수행 보드: 할 일 / 진행 중 / 완료, 시나리오별 6개 작업.
완료 처리에는 실행·결과 설명 필요. 유송민 수행 증거 추가.
진행률은 완료 작업 수 / 6. 성적·실제 실행 성공률 아님. 다른 팀원 활동은 고정 예시.

## 실행·검증

공통 구성: 실행 대상·조건·모의 콘솔·명령 바로가기·검증 결과·판단 설명.
콘솔 최근 100개 기록. 실제 장비·운영체제·API 실행 없음.

- 네트워크: PC-A `192.168.10.10` → R1 `10.0.0.1` → R2 `10.0.0.2` → PC-B `192.168.20.10`.
- 초기 오류: R2 다음 홉 `10.0.0.9`. 수정: `ip route 192.168.10.0 255.255.255.0 10.0.0.1`.
- 경로·인터페이스 확인, 양방향 ping 검증. 경로 수정 후 방향별 검증 초기화.
- 융합: `GET /schema`, `GET /status`, `TEST registered`, `TEST unknown`, `TEST privacy`.
- 융합의 근거 없는 답변 보류·개인정보 가림은 모의 규칙. 실제 보안 보장 아님.

조건 변경 시 현재 검증 초기화. 공유 조건: 전체 검사 성공·필요 조건 선택·판단 설명 입력.
추가 상황 적용 시 재분석 저장·팀 합의 필요. 이전 증거 보존.
공유 기록: 고유 ID·목표·차수·원출력·학생 설명 분리.
`project-verification-<증거 ID>` 팀 자료와 채팅 알림 생성. 반복 공유 시 이전 자료 유지.

## AI 지원·공유

팀 채팅의 「팀 메시지」 / 「AI 가이던스」 전환. 빠른 질문은 입력만 채우며 직접 전송 필요.
팀 가이던스는 기존 대화에 「TRACE AI」·「팀 가이던스」로 표시. 역할·작업 담당 자동 변경 없음.
개인 AI 대화와 팀 대화 배열 분리. 학생의 L1–L4 선택 조작 없음.
저장 정책·질문·실패·부분 검증·공유 상태에 따라 제한된 예시 응답 선택.

일반 가이던스는 자동형·승인형 모두 즉시 제공. **추가 문제 상황만** 승인 대기 대상.
직접 지도형은 교수자가 지정한 가이던스 사용. 메뉴·역할 이동 시 미전송 입력 초기화.
「AI 제안에 대한 나의 판단」: 개인 제안의 채택·수정·거부, 이유·선택 방법·선택적 검증 링크 공유.
팀 가이던스는 개인 판단 목록에서 제외.
교수자 화면: 지원 수준·주제·시간 요약, 명시적 요청·공유 증거. 개인 질문 원문 제외.
교수자 지도와 저장 평가 피드백은 같은 시나리오의 학생 화면에 반영. 새 요청은 이전 응답을 비활성화.
실제 다중 사용자 메시지·기관 전달 서비스 없음.

## 자료·저장

텍스트 작성·수정·버전 번호·검색·유형 필터·첨부·다운로드 지원.
첨부는 로컬 data URL, 파일당 2MB. 전체 직렬화 크기도 확인. 서버 업로드·문서 내용 분석 없음.
버전 번호만 증가하며 과거 수정본은 별도 보존하지 않음. 채팅 링크는 현재 자료 열기.

프로젝트 키: `trace-project-network-v2` / `trace-project-fusion-v2`.
계획·작업·증거·자료·팀/개인 대화·지원 요약·요청·피드백·실행 상태·승인 상태 저장.
기존 키는 초기 마이그레이션 입력만 사용. 교수자 과목·과제·평가·확인 기록은 별도 키 사용.
저장·전송·공유 조작으로 확정. 열린 대화상자·미저장 작업 메모는 임시 상태.
저장 실패 경고 표시. 개인 대화 분리는 로컬 UI 경계이며 서버 권한 통제 아님.

## 추가 상황

새 채팅·수행·학습 증거를 시연 규칙으로 관찰. 학생의 선행/심화 단계·상황 유형 직접 선택 없음.
자동형은 즉시 적용, 승인형은 교수자 검토. 한 번의 추가 상황 후 재검증.
정확한 시연: [학습 순환 안내](paper-learning-cycle.md).
