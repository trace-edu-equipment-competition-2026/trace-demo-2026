# 과제 생성보드

작업 모드: 과제 운영. 기존 사용자 화면 레퍼런스 유지.
목적: 교수자의 과제·AI 지원 정책 설계.
흐름: 기본 정보·목표 → 요구사항·산출물 → 평가 비율 → AI 운영 방식 → 학생 미리보기 → 생성.
첫 화면: 공통 사이드바·세 단계 표시·기본 정보·목표.
배치: 두 열 폼·전체 너비 평가 기준·운영 탭. 좁은 화면에서 메뉴 접기.

## 공통 구조

네트워크·융합 동일 생성 화면·검증 규칙. `scenarios.ts`에서 과목·목표·기준·예시 선택.
과목 출처별 지식 연결 카드 미사용. 필요한 개념은 가이던스에 반영.
과제 초안·진행 중 수업은 `workspaceKey`로 분리. 수업 전환 시 역할·메뉴·단계 유지.
생성은 로컬 저장. 실제 배포 아님. 목표 추천·AI 지원은 데모 예시.

## 상호작용

- 번호 표식: 민트·코랄·노랑·보라 파스텔.
- 상황 유형·가이던스 옵션: 추가·삭제·선택.
- 산출물 추가 / 양식 첨부 별도 조작. 파일당 2MB. 다운로드·임시 저장 지원.
- 개입 수준: 최소 / 보통 / 적극. 질문·탐색·검증 도움의 차이 표시.
- 외부 AI 감지·별도 개입 시점 선택 미지원.
- 미리보기: 과제·산출물·평가·지원 대화 예시.
- 프로필: 강병준 교수자 / 유송민 학생 전환. 실제 인증 아님.
- 정책 적용: 「과제 생성」 / 「과제 다시 저장」. 「임시 저장」은 초안.
