## 3. 경진대회 타 참가팀 대비 차별점 & 비전공 발표자용 방어 Q&A

이번 학회 경진대회에 **AI 피드백·과정평가·실습 보조(Lab-TA)** 주제가 다수 참가하므로, 발표 마무리와 질의응답에서 아래 3가지를 강조하면 확실하게 차별화됩니다.

### 3-1. 유사 AI 교육 작품 대비 TRACE만의 3대 핵심 차별점

| 비교 기준 | 일반 AI 챗봇 / 타 AI 학습 도우미 | **TRACE 플랫폼 (우리 팀)** |
| :--- | :--- | :--- |
| **1. 과제·가이드 통제권** | AI가 임의로 문제를 내거나 힌트 수위를 결정함 | **교수자가 국가 교육과정·NCS 자료를 투입**하고, **실시간 수행 상태에 맞춰 난이도(AI 힌트 범위)를 직접 조절**함 |
| **2. '정답 해줘' 방지 방식** | 채팅창에서 프롬프트로만 막아 우회 질문 시 정답 노출 | **실습 도구와 1:1 코칭이 한 화면에 결합**되어, 학생이 직접 실습을 통과하고 판단 이유를 적기 전까지 완료 불가 |
| **3. 평가 및 사후 지도** | 대화 로그만 남거나 단순 정오답 점수만 부여 | **실습 기록 + 학생 설명 + 정량적 AI 도움 횟수/수준**을 묶어 **채점 근거**로 쓰고, 즉시 **학생 개인별 지도 노트**로 변환 |

### 3-2. 발표자 안심 Q&A (네트워크 질문 완전 방어 스크립트)

| 심사위원 질문 유형 | 발표자 답변 스크립트 (그대로 답변 가능) |
