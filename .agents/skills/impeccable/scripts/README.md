# 도구 실행 파일

`impeccable`: macOS/Linux/Git Bash 로더. `impeccable.cmd`: Windows 로더.
`VERSION`: 바이너리 버전. `command-metadata.json`: 명령 정의.
`live-browser*.js`: 브라우저 변형 비교 도구. `modern-screenshot.umd.js`: 화면 캡처 라이브러리.
`data/`: 글꼴 메타데이터. 외부 실행 코드·프로토콜·주석 원본 유지.
직접 수정보다 원본 업데이트 사용. 한국어 실행 안내: `../../README.md`.
