# 명령별 참고 문서

외부 도구 원본 유지. 필요한 명령의 문서만 확인.

| 목적 | 문서 |
| --- | --- |
| 새 화면·계획 | `new-work.md`, `shape.md`, `init.md` |
| 제품·디자인 기준 | `document.md`, `craft-floor.md`, `operate.md` |
| 검토·정돈 | `audit.md`, `critique.md`, `polish.md` |
| 오류·반응형·성능 | `harden.md`, `adapt.md`, `optimize.md` |
| 글자·간격·색·모션 | `typeset.md`, `layout.md`, `colorize.md`, `animate.md` |
| 브라우저 변형 비교 | `live.md`, `live-setup.md`, `generate.md` |
| 설정·진단 | `routing.md`, `hooks.md`, `doctor.md` |
| 위임 대체 절차 | `degraded/` |

다른 이름의 문서는 원본 `SKILL.md` 명령 표 참조. 앱 코드·시연 안내는 루트 `docs/` 사용.
