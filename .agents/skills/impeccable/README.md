# Impeccable 사용

UI 디자인·검토 스킬. 원본 버전: `SKILL.md`의 `metadata.version` 확인.

- `SKILL.md`: 적용·문맥·명령 선택 규칙.
- `reference/`: 명령별 상세 절차.
- `scripts/`: 문맥 로더·브라우저 지원 도구.
- `agents/`: 위임 검토 설정.
- `LICENSE`: 원본 라이선스.

앱 실행에 로더 불필요. UI 수정 요청 시 해당 스킬 사용.
상세 예시·실행 명령: `../README.md`.
외부 도구 원본 유지. 프로젝트 기준은 루트 `PRODUCT.md`, `DESIGN.md` 우선.
